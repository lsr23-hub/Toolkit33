# 工具卡片数据契约

## 源文件与生成

- 源文件：`sql/tools.sql`
- 生成脚本：`scripts/build-tools.mjs`
- 生成文件：`src/data/tools.json`
- 生成命令：`npm run data`

不要直接编辑 `src/data/tools.json`。任何新增或修改都先落在 SQL 源文件，再运行生成脚本。

## 字段

| 字段 | 规则 |
| --- | --- |
| `name` | 卡片展示名称；保留项目官方名称的大小写和标点，除非用户要求改名 |
| `url` | 项目公开入口；必须是完整 `http` 或 `https` URL，并保持唯一 |
| `category` | 只能使用现有分类：`AI 编程`、`前端设计`、`部署运维`、`视频创作`、`素材资源`、`科研成长`、`效率工具`、`数据与文档`、`安全测试` |
| `keywords` | SQL 中为 JSON 数组字符串；当前卡片约定 3 个中文短语，便于搜索和扫描 |
| `description` | 中文事实性简介；覆盖项目类型、核心能力和主要使用场景，不添加未被来源支持的数字或承诺 |
| `icon_url` | `https://icons.duckduckgo.com/ip3/<hostname>.ico`，hostname 从 `url` 解析得到 |
| `sort_order` | 正整数；新增条目取当前最大值加 1，除非用户指定位置 |
| `is_featured` | SQLite 整数 `0` 或 `1`；默认 `0` |

## 分类提示

- `AI 编程`：编码代理、AI 编程课程、AI Agent、AI 技能、AI 绘图提示词
- `前端设计`：组件、动画、设计系统、浏览器自动化与前端工程
- `部署运维`：自托管、PaaS、服务器部署
- `视频创作`：代码视频、生成式视频、剪辑与镜头模板
- `素材资源`：图片、视频、笔刷、纹理、样机、设计模板
- `科研成长`：科研自动化、论文写作、求职面试、个人成长
- `效率工具`：日程、项目管理、会议记录和个人工作流
- `数据与文档`：文档转换、网页抓取、公共 API 和数据处理
- `安全测试`：安全扫描、渗透测试和发布前检查

若一个项目同时符合多个分类，按其官网强调的主要用途选择，并在研究结果中说明理由。
